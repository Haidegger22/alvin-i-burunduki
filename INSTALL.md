# Установка и пересборка — «Элвин и бурундуки»

Игра браузерная: ставить нечего, достаточно Chromium. Ниже — как её запустить,
а также как заново сгенерировать графику, пересобрать музыку и записать видео.
Все команды проверены на Orange Pi Zero 3W (Debian 13, Trixie).

---

## 1. Что должно быть установлено

| Что | Зачем | Проверка |
|---|---|---|
| Chromium (или любой современный браузер) | запуск игры | `chromium --version` |
| Python 3 | локальный сервер, инструменты | `python3 --version` |
| `python3-pil` (Pillow) | подготовка спрайтов из картинок | `python3 -c "import PIL; print(PIL.__version__)"` |
| Node.js 20+ | только для записи видео через CDP | `node --version` |
| `ffmpeg` | только для видео и конвертации звука | `ffmpeg -version` |

Установка на Debian, если чего-то нет:

```bash
sudo apt install -y python3-pil nodejs ffmpeg chromium
```

## 2. Запуск игры

**Самый простой способ** — открыть файл напрямую:

```bash
cd ~/games/alvin-chipmunks
chromium index.html
```

Так игра работает полностью, но **звуковые эффекты могут не загрузиться**: браузер
запрещает `fetch()` к файлам по схеме `file://`. Музыка через `<audio>` играет.

**Полноценный способ** — поднять локальный сервер (звук работает весь):

```bash
cd ~/games/alvin-chipmunks
python3 -m http.server 8123 --bind 127.0.0.1
```

и открыть в браузере `http://127.0.0.1:8123/index.html`.
Остановить сервер — `Ctrl+C` в том окне.

> Браузер не даёт включать звук до первого действия пользователя. Тема уровня
> стартует после нажатия **Enter** на титульном экране — это нормально, не ошибка.

**Демо-режим** (игра играет сама, нужен для проверки и записи видео):

```
http://127.0.0.1:8123/index.html#demo
```

В этом режиме игру двигает не таймер браузера, а команда `window.__step(n)` извне —
так запись кадров не зависит от того, тормозит ли браузер фоновую вкладку.

## 3. Пересборка графики

Графика генерируется через MiniMax (`image-01`). Ключ должен лежать в `~/.hermes/.env`
строкой `MINIMAX_API_KEY=...` — скрипт читает его сам, в коде ключа нет.

```bash
cd ~/games/alvin-chipmunks

# 1) сгенерировать все 31 картинку в raw/ (около 5-10 минут)
python3 tools/build_assets.py

# 2) проверить, что получилось: валидность PNG, размеры, наличие фона
python3 tools/validate_assets.py

# 3) убрать случайные крапины и подписи по углам
python3 tools/clean_assets.py

# 4) вырезать фон, обрезать по контуру, уменьшить до игрового размера
python3 tools/prepare_sprites.py
```

После шага 4 готовые спрайты и фоны лежат в `assets/sprites/`. Игра подхватит их
при следующем запуске.

**Список ассетов и промпты** — в `tools/assets_def.py`: имя файла, промпт, пропорции.
Хочешь заменить одного героя — поправь промпт там и запусти только нужную генерацию:

```bash
# один ассет вручную, если нужно быстро
python3 tools/mmgen.py "pixel art sprite, retro NES 8-bit style, single cartoon chipmunk \
 in a red sweater, standing, side view, centered, plain solid magenta background, no text" \
 raw/chr_alvin_stand.png --ratio 1:1
python3 tools/prepare_sprites.py
```

Что делает подготовка спрайтов: берёт цвет фона по периметру картинки (генератор
может дать и чистую magenta, и розово-малиновый оттенок), удаляет фон с допуском,
отдельным проходом подчищает кайму по краю объекта, обрезает по контуру и уменьшает
до игрового размера с палитрой из 24 цветов — чтобы спрайт выглядел как пиксель-арт,
а не как шум. Настройки (размеры, допуск) — в начале `tools/prepare_sprites.py`.

## 4. Пересборка музыки и звуков

Синтезатор написан на чистом Python, без numpy и внешних сервисов: три канала как
на NES (прямоугольный, треугольный бас, шумовые ударные).

```bash
cd ~/games/alvin-chipmunks
python3 tools/make_music.py
```

Скрипт создаёт в `assets/audio/` файлы `title`, `level`, `victory`, `damage`, `item`,
`gameover`, `sfx_jump`, `sfx_throw`, `sfx_crate_break` — в WAV и сразу в OGG
(конвертация через `ffmpeg`; если `ffmpeg` нет, останутся только WAV, а игра
возьмёт синтезированный запасной сигнал из `js/assets.js`).

Мелодии, темп и структура лежат внутри скрипта отдельными блоками — правится текстом.

## 5. Запись видео прохождения

Видео снимается через Chrome DevTools Protocol: скрипт сам двигает игру пошагово
и сохраняет кадры, затем `ffmpeg` собирает их в mp4.

```bash
cd ~/games/alvin-chipmunks

# 1) поднять headless-Chromium с портом отладки
chromium --headless=new --no-sandbox --disable-gpu --hide-scrollbars --mute-audio \
  --remote-debugging-port=9333 --user-data-dir=/tmp/chr-shoot about:blank &

# 2) поднять локальный сервер с игрой
python3 -m http.server 8123 --bind 127.0.0.1 &

# 3) записать 25 секунд игры: 12 кадров в секунду, по 5 игровых тиков на кадр
node tools/shoot.js --port 9333 \
  --url "http://127.0.0.1:8123/index.html#demo" \
  --out /tmp/game_frames --fps 12 --seconds 25 --ticks 5

# 4) собрать видео со звуком (третий аргумент — аудиофайл, четвёртый — кадров/с)
tools/make_video.sh /tmp/game_frames video/alvin-level1.mp4 assets/audio/level.ogg 12
```

Полезное рядом:

```bash
# посмотреть состояние игры в открытой вкладке (без перезапуска записи)
node tools/probe.js --port 9333 --expr "JSON.stringify({state: window.__game.state, px: window.__game.players[0].x})"

# открыть игру заново и подождать 10 секунд перед осмотром
node tools/probe.js --port 9333 --open "http://127.0.0.1:8123/index.html#demo" --wait 10
```

`tools/shoot.js` без `--ticks` работает в живом режиме: нажимает клавиши как человек
(сценарий в `buildTimeline`) и снимает кадры по часам — годится для проверки управления.

## 6. Структура каталогов

```
index.html               точка входа
js/assets.js             загрузка спрайтов, звук (WebAudio + файлы)
js/world.js              уровень и столкновения
js/game.js               физика, герой, ящики, враги, экраны, авто-пилот демо
tools/mmgen.py           генератор картинок (MiniMax)
tools/assets_def.py      список ассетов с промптами
tools/build_assets.py    пакетная генерация + перегенерация неудачных
tools/validate_assets.py проверка PNG
tools/clean_assets.py    чистка крапин
tools/prepare_sprites.py вырезание фона, обрезка, масштаб
tools/make_music.py      чиптюн-синтезатор
tools/shoot.js           запись кадров через CDP
tools/probe.js           осмотр состояния игры
tools/make_video.sh      сборка mp4
raw/                     сырые картинки от генератора
assets/sprites/          готовые спрайты и фоны
assets/audio/            музыка и звуки
screenshots/, video/     скриншоты и записанное прохождение
```

## 7. Частые проблемы

| Проблема | Причина и решение |
|---|---|
| Нет музыки на титульном экране | Браузер запрещает звук до действия пользователя. Нажми Enter — тема уровня заиграет |
| Не слышно звуковых эффектов | Игра открыта как `file://`. Подними локальный сервер (раздел 2) |
| Персонаж нарисован «палочками», фон — заливка | Не загрузились спрайты. Проверь, что файлы лежат в `assets/sprites/` и путь в `js/game.js` (`SpriteBank.load(SPRITE_NAMES, "assets/")`) совпадает |
| Спрайты с розовой каймой | Фон вырезан слишком узким допуском. Увеличь `BG_TOLERANCE` в `tools/prepare_sprites.py` и перезапусти его |
| Запись видео идёт «рывками», игра почти не двигается | Браузер тормозит фоновую вкладку. Используй пошаговый режим: `#demo` в адресе и `--ticks 5` в `tools/shoot.js` |
| `window.__step is not a function` | В адресе нет `#demo`. Режим доступен только на `index.html#demo` |
| Гибель в яме кажется несправедливой | Ширина ямы и сила прыжка — в `js/world.js` (`ground`) и `js/game.js` (`JUMP_V`, `HOLD_GRAV`). Прыжок с удержанием пролетает около 57 пикселей при яме в 48 |
| Герой упирается в первый ящик и стоит | Так и задумано: ящики твёрдые, их нужно взять (X) или перепрыгнуть |
