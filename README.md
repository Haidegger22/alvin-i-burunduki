# 🐿️ Элвин и бурундуки

Платформер в духе NES «Чип и Дейл»: три бурундука, ящики вместо оружия и враги-роботы.
Игра браузерная — открывается в Chromium двойным щелчком по `index.html`, ничего ставить не нужно.

**Механика — как в оригинале:** прямой атаки нет. Ящик можно поднять, бросить во врага,
забраться на него или спрятаться внутри — тогда первый удар врага разобьёт ящик, а сам враг погибнет.

## Управление

| Действие | Первый игрок | Второй игрок (вдвоём) |
|---|---|---|
| Идти влево / вправо | ← → | A / D |
| Прыжок (чем дольше держишь, тем выше) | Z | W |
| Взять / бросить ящик | X | C |
| Спрятаться в ящик | ↓ | S |
| Начать игру / выбрать героя | Enter, ← → | — |
| Игра вдвоём | клавиша 2 на титульном экране | — |

## Что есть в игре

- **Три героя** с разными цветами: Элвин (красный), Саймон (синий), Теодор (зелёный)
- **Уровень «Лесная опушка»** длиной 240 тайлов: ямы, деревянные платформы, ящики, бонусы
- **Три вида врагов:** механический бульдог (бросается в атаку, увидев героя), робо-крыса (прыгает), пчела-робот (пикирует)
- **Бонусы:** звёзды и цветы — очки, жёлудь — лечит сердце
- **Ямы:** падение отнимает сердце и возвращает на безопасное место; когда сердца кончаются — теряется жизнь
- **Финиш:** дверь в конце уровня
- **Музыка и звуки:** восемь треков в стиле NES (2A03): пунктирный бас, свинцовый голос, шумовые ударные

## Запуск

```bash
# самый простой способ — открыть файл в браузере
chromium index.html

# либо поднять локальный сервер (тогда работают ещё и звуки через fetch)
cd /home/orangepi/games/alvin-chipmunks
python3 -m http.server 8123 --bind 127.0.0.1
# и открыть http://127.0.0.1:8123/index.html
```

Со звуком есть нюанс: браузер не даёт играть музыку до первого действия пользователя —
поэтому тема уровня включается после нажатия Enter на титульном экране.

Подробная установка, пересборка графики и музыки, запись видео — в [INSTALL.md](INSTALL.md).

## Как сделаны ассеты

- **Графика** — генерация через MiniMax (`image-01`), 31 картинка: три героя по пять поз,
  враги в двух позах, предметы, три фона. Фон вырезается автоматически: цвет берётся
  по периметру картинки, удаляется с допуском, кайма подчищается отдельным проходом,
  спрайт обрезается по контуру и уменьшается до игрового размера с палитрой 24 цвета.
- **Музыка и звуки** — свой чиптюн-синтезатор на чистом Python (без внешних библиотек):
  три канала как на NES, экспорт в WAV и OGG.

## Структура

```
index.html              точка входа
js/assets.js            загрузка спрайтов, звук, WebAudio-запасной вариант
js/world.js             уровень и столкновения с тайлами
js/game.js              физика, герой, ящики, враги, экраны, авто-пилот для демо
tools/mmgen.py          генерация картинок через MiniMax
tools/prepare_sprites.py вырезание фона, обрезка, масштаб
tools/make_music.py     чиптюн-синтезатор (музыка и эффекты)
tools/shoot.js          запись кадров через CDP (умеет нажимать клавиши и вести демо)
tools/probe.js          быстрый осмотр состояния игры в браузере
tools/make_video.sh     сборка видео из кадров (ffmpeg)
raw/                    сырые картинки от генератора
assets/sprites/         готовые спрайты и фоны
assets/audio/           музыка и звуки (ogg + wav)
```

## Идея и авторство

Игра сделана по мотивам NES-версии «Chip 'n Dale: Rescue Rangers» (Capcom, 1990) —
механика с ящиками целиком оттуда. Персонажи — Элвин, Саймон и Теодор из «Элвина и бурундуков».
Это фан-работа без коммерческого использования: спрайты сгенерированы, музыка написана скриптом,
код оригинальный. Лицензия MIT — делай что хочешь, но без гарантий 🙂
